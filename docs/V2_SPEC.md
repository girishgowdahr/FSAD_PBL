# URL Shortener with Analytics: V2 Enhancements Spec

> This is the preserved V2 specification for the MCA Semester III Project-Based Learning (PBL) application.

## 1. Enhancements Summary
- **E1: Authentication + Personal Dashboards:** JWT auth, bcrypt password hashing, scoped links/analytics.
- **E2: Custom Aliases + Link Expiry:** 4-20 char custom codes, 1 min - 365 day expiry, 410 Gone status.
- **E3: QR Codes + CSV Export:** Canvas QR code generation + PNG download, Excel-ready CSV export with formula injection protection and UTF-8 BOM.
- **E4: Search, Filter, Dark Mode, UI Polish:** Debounced search, status filter (all/active/expired), sort (newest/oldest/clicks), pagination, light/dark themes, toast system, skeletons, confirmation modals.
